Este repositorio contiene un cuaderno digital sobre el Efecto Doppler, desarrollado como material académico para el estudio y comprensión del comportamiento de las ondas cuando existe movimiento relativo entre la fuente emisora y el observador.

El cuaderno aborda los fundamentos teóricos, ejemplos prácticos, ejercicios y aplicaciones físicas del fenómeno Doppler en distintos contextos.
